# discovery-to-demo

This is a placeholder project coming from a conversation between myself and Luke. 

This is regarding an application or a job that we can do which takes the input of the discovery notes from either a customer meeting or a discovery workshop. The outcome will be guidance and instructions for the sales team to action by connecting these discovery notes with our latest demo available in the demo hub. 

This won't be just a link to the demo, but also a breakdown of the persona and a full storyline that showcases the value of our products by demonstrating the demo. 

This is just the first step to help us put this idea together, and we will kick off the project soon.
